# Алгоритм битонной сортировки (Bitonic Sort)

Реализация алгоритма битонной сортировки на Python.

## Описание

Bitonic Sort - это параллельный алгоритм сортировки, основанный на построении 
и слиянии битонных последовательностей.

**Битонная последовательность** - это последовательность чисел, которая сначала 
монотонно возрастает, а затем монотонно убывает (или наоборот).

- **Время работы**: O(n log² n)
- **Пространственная сложность**: O(1) (сортировка in-place)
- **Особенность**: Алгоритм особенно эффективен для параллельных вычислений
- **Оптимальный размер**: Алгоритм работает лучше всего, когда размер массива 
  является степенью двойки (2, 4, 8, 16, 32, ...), но может работать с любым размером

## Структура проекта

- `main.py` - основная реализация алгоритма битонной сортировки
- `test_sort.py` - unit-тесты для модуля сортировки

## Алгоритм

Битонная сортировка работает в два основных этапа:

1. **Построение битонной последовательности**:
   - Рекурсивно разделяет массив пополам
   - Сортирует одну половину по возрастанию, другую по убыванию
   - Это создает битонную последовательность

2. **Слияние битонной последовательности**:
   - Сравнивает соответствующие элементы из двух половин
   - Меняет их местами при необходимости
   - Рекурсивно применяет слияние к каждой половине
   - Результат - полностью отсортированная последовательность

## Использование

```python
from main import bitonic_sort

arr = [12, 11, 13, 5, 6, 7, 8, 4]
sorted_arr = bitonic_sort(arr)
print(sorted_arr)  # [4, 5, 6, 7, 8, 11, 12, 13]
```

**Примечание**: Алгоритм работает с массивами любого размера, но наиболее эффективен 
для массивов размером, равным степени двойки (2, 4, 8, 16, 32, 64, ...).
